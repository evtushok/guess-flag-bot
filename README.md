# Бот Telegram Угадай Флаг

Telegram-бот для увлекательной игры в угадывание флагов стран мира. Пользователи видят флаг и должны угадать, какой стране он принадлежит.

**Отлично подходит для:**
- изучения географии
- убийства времени
- соревнования с друзьями
- образовательных целей

**В боте есть 3 режима игры:**
- бесконечный режим (для заучивания и тренировки, заврешение по желанию)
- на время (постарайтесь угадать максимальное количество флагов за определенное количество времени)
- классика (3 жизни, после 3 ошибок игра завершается)

---

## Требования

- Python 3.8+
- Токен Telegram Bot API (генерация через @BotFather в Telegram командой /newbot)

## Использование

### 1. Клонируйте репозиторий
```bash
git clone https://github.com/evtushok/guess-flag-bot.git
cd guess-flag-bot
```
В config.py вставляйте токен в BOT_TOKEN, который вам выдал @BotFather в Telegram
### 2. Создайте виртуальное окружение
```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate     # Windows
```

### 3. Установите зависимости
```bash
pip install -r requirements.txt
```

### 4. Запуск в режиме polling (для разработки)
```bash
python bot.py
```

### Команды бота

- `/start` — Начать игру
- `/help` — Полноценные правила игры

### Правила игры

1. Бот показывает флаг страны
2. Вам нужно выбрать правильный ответ из 4 вариантов
3. За правильный ответ начисляются очки
4. Старайтесь набирать наибольшее количество очков

- [aiogram](https://docs.aiogram.dev/) — Фреймворк для Telegram Bot API
- [aiohttp](https://docs.aiohttp.org/) — Асинхронный HTTP клиент
